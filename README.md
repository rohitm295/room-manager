# 🏠 RoomFlow — Room & Utility Manager

**Powered by Jatav Industries**

RoomFlow is a personal room-rent and utility management web application designed to manage rent, electricity bills, tenants, properties, payments, and important rental documents in one place.

## ✨ Features

- 🔐 Secure user authentication with Firebase
- 🏢 Property and room management
- 👥 Tenant management
- 💰 Monthly rent tracking
- ⚡ Electricity meter readings and bill calculations
- 🧾 Payment record management
- 🔔 Upcoming and overdue bill reminders
- 📊 Reports and CSV exports
- 🛠️ Maintenance record management
- 📄 Rental agreement records
- 📁 Document information management
- ⚙️ User profile and settings
- ☁️ Cloud-based data storage with Cloud Firestore

## 🚀 Project Setup

1. Open this repository on GitHub.
2. Ensure the required HTML, CSS, and JavaScript files are present.
3. Configure Firebase using your own Firebase project settings.
4. Enable the required Firebase Authentication methods.
5. Configure Firestore security rules before storing user data.
6. Enable GitHub Pages in the repository settings.

## 🔒 Security

RoomFlow uses Firebase Authentication and Firestore security rules to protect user-specific records.

Never commit private credentials, passwords, service-account keys, or other sensitive information to a public repository.
